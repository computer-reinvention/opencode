Apply all pending patches through the cascade-editing pipeline: merge notes, generate source + prose, cascade to neighbour symbols, run compile + LSP fixup, and commit atomically. `note` is the unifying intent across all patches and is required. The pipeline owns well-formedness (compiles, LSP-clean); you own correctness — run tests after. If it returns blocking unresolved items, address them (often a follow-up trie_patch, or a backup fs_edit with force for non-symbol regions) and apply again.
