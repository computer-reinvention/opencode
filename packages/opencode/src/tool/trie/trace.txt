Trace the call graph outward from a symbol up to `depth` hops. Returns the root, every reachable node within depth, and the directed edges between them. Use to understand a change's blast radius (direction="callers") or what a function ends up doing (direction="callees"). For prose on a specific node, follow up with trie_read on that qname. Prefer this over repeated trie_read calls when traversing topology.
