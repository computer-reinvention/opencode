BACKUP TOOL (fs_read). Read a raw file or directory from the filesystem. PREFER trie_read for code — it returns a symbol's prose plus callers/callees for a qname, or line-numbered source for a path.

Use this fallback tool when you need capabilities trie_read does not have:
- reading images or PDFs (returned as attachments),
- listing a directory's entries,
- reading files trie does not index (non-Python code, configs, docs).

Usage:
- filePath should be an absolute path.
- Returns up to 2000 lines from the start by default; use offset (1-indexed) and limit for windows.
- Lines are returned prefixed with their line number as `<line>: <content>`.
- Can read image files and PDFs as file attachments.
