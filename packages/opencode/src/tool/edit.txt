BACKUP TOOL (fs_edit). Exact string replacement in a file. PREFER the trie patch pipeline for indexed code: trie_patch (modify a symbol), trie_create_symbol / trie_delete_symbol / trie_rename_symbol (structural), then trie_patch_apply.

This tool is REFUSED on trie-indexed code files (it will tell you to use the patch flow). It remains the right tool for:
- non-indexed files (configs, docs, non-Python code),
- sub-symbol or non-symbol-region edits trie cannot express (one-line tweaks, module-level constants, file headers),
- cases where the patch pipeline returns blocking unresolved items.
Pass force=true to override the refusal for an indexed file when you have a specific reason.

Usage:
- Read the file first (trie_read with show_source, or fs_read).
- oldString must match exactly (including indentation) and uniquely; use replaceAll to replace every occurrence.
