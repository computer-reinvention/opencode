BACKUP TOOL (fs_grep). Raw regex search over file contents. PREFER trie_grep for all code search — it searches the indexed symbol graph and returns call-graph context.

Use this fallback tool ONLY when:
- the files are not indexed by trie (non-Python code, configs, docs, JSON/YAML, lockfiles), or
- trie is unavailable, or
- you specifically need raw line-level regex matches across arbitrary files.

- Fast content search that works with any codebase size.
- Full regex syntax (e.g. "log.*Error", "function\s+\w+").
- Filter files with the include parameter (e.g. "*.js", "*.{ts,tsx}").
- Returns file paths and line numbers, sorted by modification time.
