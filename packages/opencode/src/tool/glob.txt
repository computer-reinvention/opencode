BACKUP TOOL (fs_glob). Find files by name/path pattern (e.g. "**/*.ts", "Dockerfile"). trie has no filename-search tool yet, so this is the tool for locating files by path.

- Fast file pattern matching at any codebase size.
- Supports glob patterns like "**/*.js" or "src/**/*.ts".
- Returns matching file paths sorted by modification time.
- For searching file CONTENTS in code, prefer trie_grep; use this only for filename/path matching.
