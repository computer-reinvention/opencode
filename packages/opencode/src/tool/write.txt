BACKUP TOOL (fs_write). Create or overwrite a file. PREFER trie_create_symbol to add a new symbol to an indexed file via the patch pipeline.

This tool is REFUSED when overwriting an existing trie-indexed code file (use the patch flow instead). It remains the right tool for:
- creating NEW files of any kind (configs, docs, scripts, new modules),
- writing non-indexed / non-Python files.
Pass force=true to override the refusal for an existing indexed file.

Usage:
- ALWAYS prefer editing an existing file over creating a new one.
- NEVER proactively create documentation files unless explicitly requested.
